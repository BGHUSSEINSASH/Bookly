# Bookly — منصة حجز المزارع والفنادق والطيران والأنشطة السياحية

> منصة سياحية وعقارية متعددة المزوّدين بأولوية عربية: حجز المزارع والاستراحات والشاليهات والفنادق والشقق الفندقية وتذاكر الطيران وتأجير السيارات والرحلات السياحية — في تطبيق واحد وموقع متكامل مع دفع إلكتروني ومحفظة رقمية ونظام نقاط.

```
bookly/
├── apps/
│   ├── api/        NestJS 11 + Prisma 6 + PostgreSQL     → المنصة الخلفية
│   ├── web/        Next.js 15 + Tailwind v4              → الموقع (RTL + وضع ليلي)
│   └── mobile/     Flutter 3.24 + flutter_map            → تطبيق Android/iOS
├── packages/
│   └── shared/     ثوابت وأدوات مشتركة (TypeScript)
├── scripts/         اختبار دخان للـ API + فحص صفحات الويب
└── docker-compose.yml
```

---

## التشغيل السريع

```bash
npm install

npm run docker:up          # PostgreSQL + Redis + MinIO
npm run db:migrate         # تطبيق المخططات
npm run db:seed            # تعبئة البيانات العربية + الصور الاحترافية

npm run dev:api            # http://localhost:4000/api/v1  (+ /docs)
npm run dev:web            # http://localhost:3000

cd apps/mobile && flutter pub get && flutter run
```

> منفذ PostgreSQL = `5433` افتراضيًا (لتفادي التعارض مع قواعد بيانات أخرى). غيّره من `.env`.

لغة تصميم واحدة عبر الموبايل: تركوازي حيّ + ليموني للتمييز،
بطاقات بيضاء على خلفية شبه بيضاء — مستوحاة من تطبيقات الضيافة العقارية الحديثة (شناشيل).

| **الليموني (تمييز + CTA)** | `#D7E64B` · `#BFCF35` داكن · `#F4F8D9` خلفية ناعمة |

## البنية الخلفية

- **37 نموذجًا** في Prisma · 19 وحدة NestJS
- المصادقة: JWT (15د) + Refresh Token مع تدوير · bcrypt (12 جولة) · حراسة أدوار
- الإشعارات: خدمة موحّدة `NotificationsService` · تولّد تلقائيًا عند إنشاء/تأكيد/إلغاء الحجز للعميل والمزوّد · واجهات `GET /notifications` · `GET /notifications/unread-count` · `PATCH /:id/read` · `PATCH /read-all`
- الكتالوج: `Property` موحّد (مزرعة/شاليه/استراحة/فندق/شقة) · فلاتر بحث بالتوفّر الزمني
- الحجوزات: 4 أهداف (عقار/طيران/سيارة/رحلة) · تسعير · كوبون · نقاط · عمولة · محفظة
- الدفع: Visa/Mastercard · Apple Pay · Google Pay · PayPal · زين كاش · آسيا حوالة · فاست باي
- المكافآت: نقطة لكل 10 وحدات · 100 نقطة = 100 وحدة · 4 مستويات
- العمولة: مزارع 12% · فنادق 10% · سيارات 10% · رحلات 12% · طيران 3%

## ملاحظات تقنية مهمة

- **مسار المجلد عربي** يكسر Gradle. الحل المُطبّق:
  ```bash
  subst B: "C:\Users\Cloud\Desktop\تطبيق بوكلي"
  cd B:\apps\mobile && flutter build apk --debug
  ```
- **Flutter 3.24** لا يدعم `Color.withValues` — المستخدَم `withOpacity`.
- `flutter_map 7.0.2` هو آخر إصدار متوافق مع Flutter 3.24 (8.x يتطلب 3.27+).
- استجابات الـ API موحّدة: `{ success, data, meta, timestamp }` مع `meta` للترقيم.
- المبالغ `Decimal(12,2)` — لا أرقام عائمة.
